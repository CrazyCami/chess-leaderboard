# School Chess League

A Next.js and TypeScript starting point for a school year-group chess league. The current page uses fictional placeholder players only.

## Run locally

1. Install Node.js (20.9 or newer) and npm.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open [http://localhost:3000](http://localhost:3000).

No Supabase connection, authentication, Chess.com importer, or real student data is included yet.

## Team roles

- Person 1 owns the website interface and visual design.
- Person 2 owns backend logic, the database, imports, duplicate prevention, and ratings.
- Person 3 owns league rules, review-process decisions, and QA.

Keep all development data fictional. Privileged credentials must stay server-side and must never use a `NEXT_PUBLIC_` environment variable.
